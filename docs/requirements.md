# 需求规格说明

## 项目背景

流浪动物救助组织常用群聊和表格记录信息，存在救助进度分散、领养审核不透明、志愿者和捐赠记录难公示等问题。本系统建设统一 Web 信息公示平台，提升救助流程透明度与协作效率。

## 用户角色

| 角色 | 说明 | 权限 |
| --- | --- | --- |
| 公众用户 | 普通访客 | 浏览动物、查看救助案例、提交线索、申请领养、报名志愿者、登记捐赠 |
| 管理员 | 救助组织工作人员 | 登录后台、维护动物档案、维护救助案例、审核申请、管理志愿者、查看捐赠 |

## 功能需求

1. 首页公示：展示动物档案、待领养、进行中救助、志愿者和累计捐赠金额。
2. 动物信息：支持列表、状态/关键字筛选、详情展示。
3. 领养申请：用户填写申请人、电话、地址、经验和理由，管理员审核。
4. 救助线索：用户提交地点、紧急程度、联系方式，管理员维护处理进度。
5. 志愿者报名：记录技能、可服务时间和联系状态。
6. 捐赠登记：记录资金、物资或服务捐赠，后台汇总金额。
7. 后台管理：登录后进行动物、案例、申请、志愿者和捐赠管理。

## 非功能需求

- 可维护性：采用 MVC/BCE 分层，职责清晰。
- 易用性：页面响应式布局，前台流程简洁。
- 数据完整性：通过实体校验、外键和索引保证基础数据质量。
- 安全性：后台会话鉴权，管理员密码保存 SHA-256 哈希。
- 可部署性：支持 IDEA 导入、Maven 构建、MySQL 部署。
